# Engine Specs

Use this directory for long-lived Vultra engine specifications.

Good spec topics include:

- asset pipeline and `vasset` behavior
- `.vproject`, `.vscn`, `.vrg.json`, and `.vrp.lua` formats
- rendering pipeline architecture
- Lua scripting and binding surfaces
- MCP and AI Harness capabilities

Each spec should describe intent, public interfaces, constraints, and acceptance
criteria. Do not use specs as temporary work logs.
