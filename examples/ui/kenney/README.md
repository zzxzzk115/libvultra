# Kenney UI Pack sample assets

These PNGs are an unmodified subset of [Kenney UI Pack 2.0](https://kenney.nl/assets/ui-pack) (2024-06-12). Blue/Default provides the buttons, icons, toggles, slider handle and stars; Green/Default and Grey/Default provide the Save and disabled button states; Yellow/Default provides the regular and small down arrows. They are used only by `example-ui`; the built-in VGui skin does not depend on them.

Kenney distributes the pack under Creative Commons Zero (CC0). The archive's original notice is preserved in [License.txt](License.txt).
